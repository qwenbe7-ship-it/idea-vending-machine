# v0.4 Autonomous Due Diligence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make one-click server-owned autonomous due diligence the primary Idea Vending Machine workflow while retaining ChatGPT Plus Bridge only as an advanced fallback.

**Architecture:** Reuse the verified `run_evolution()` runtime and OpenAI Responses adapter. Add server-derived automation evidence, role-separated provider instances, readiness semantics that prefer autonomous mode when configured, and a UI whose primary submit calls `/api/evolve` directly. Existing Bridge endpoints and approval gates remain unchanged.

**Tech Stack:** Python 3.11, stdlib `http.server`, OpenAI Responses API transport, vanilla HTML/CSS/JS, unittest, Playwright Chromium.

**Spec:** `docs/superpowers/specs/2026-09-17-v0.4-autonomous-due-diligence-design.md`

## Global Constraints

- No browser-supplied API key or model configuration.
- `/api/evolve` accepts exactly `{idea}`.
- Provider outputs never set official GO/MODIFY/HOLD/KILL or approval state.
- Exactly ten candidates remain required for completed E2A runs.
- GO/MODIFY require explicit human approval before spec/design/plan.
- HOLD/KILL remain blocked.
- Bridge remains available but is not the default product path once API mode is configured.
- No GREEN claim without fresh unit/integration and Chromium evidence.
