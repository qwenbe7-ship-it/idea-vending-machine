# Idea Vending Machine v0.2 Development Package Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate deterministic `spec.md`, `design.md`, and `plan.md` development documents from one validated idea analysis and expose them through the existing dependency-free web app.

**Architecture:** Keep `analyze_idea()` unchanged as the source of truth. Add a pure package generator, expose it through `POST /api/package`, and let the browser preview/download the returned Markdown without server-side file writes.

**Tech Stack:** Python 3.11 standard library, `unittest`, vanilla HTML/CSS/JavaScript, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-16-v0.2-development-package-design.md`

## Global Constraints

- No external LLM API.
- No new third-party dependencies.
- Same input and analysis must produce byte-identical documents.
- Generated package contains exactly `spec.md`, `design.md`, and `plan.md`.
- Generated content must not contain `TBD` or `TODO` placeholders.
- Existing `/api/analyze` behavior must remain compatible.
- `scripts/verify.py` remains the single Production Gate entry point.

- [ ] **Step 1: Write failing tests** proving exact filenames, deterministic output, shared project ID, verbatim acceptance criteria in `spec.md`, and absence of placeholder markers.

```python
class PackageGeneratorTests(unittest.TestCase):
    def setUp(self):
        self.idea = "업로드된 영수증에서 항목을 추출하고 표로 정리하는 자동화 도구"
        self.analysis = analyze_idea(self.idea)

    def test_returns_exact_required_documents(self):
        documents = generate_development_package(self.idea, self.analysis)
        self.assertEqual(set(documents), {"spec.md", "design.md", "plan.md"})

    def test_same_input_is_byte_identical(self):
        self.assertEqual(
            generate_development_package(self.idea, self.analysis),
            generate_development_package(self.idea, self.analysis),
        )
```
