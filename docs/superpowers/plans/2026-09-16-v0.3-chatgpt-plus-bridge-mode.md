# ChatGPT Plus Bridge Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make ChatGPT Plus Bridge Mode the default zero-API-cost assessment path while preserving the existing deterministic evidence, ten-candidate, independent-evaluator, official-decision, human-approval, and development-handoff contracts.

**Architecture:** Split the verified evolution runtime at the existing evaluator boundary into a trusted Forge phase and a finalize-with-evaluation phase, without changing API-mode behavior. Bridge Mode exports a versioned Forge package, replays imported untrusted Forge outputs through the same deterministic Forge phase, generates a fresh independent Judge package from the trusted Forge artifact, then replays the imported Judge critique through the same finalize path. The browser never supplies trusted IDs, decisions, provider settings, or approval state.

**Tech Stack:** Python 3.11 stdlib HTTP server, existing Idea Vending Machine deterministic modules, JavaScript DOM APIs, Playwright 1.63.0 test-only Chromium.

**Spec:** `docs/superpowers/specs/2026-09-16-v0.3-chatgpt-plus-bridge-mode-design.md`

## Global Constraints

- Bridge version is exactly `ivm-bridge-v1` for this implementation.
- Bridge Mode requires no `OPENAI_API_KEY` and is the default owner-operated mode.
- Existing OpenAI API mode remains intact and optional.
- Forge and Judge are separate passes; Judge packages never contain Forge rankings, preferred candidate, official verdict, or human approval.
- Exactly ten canonical candidate families are required, one candidate per family.
- Imported Bridge payloads are untrusted and cannot directly set trusted IDs, Reality Verdicts, GO/MODIFY/HOLD/KILL, confidence, selected concept, evolved idea, or human approval.
- Existing Evidence Graph integrity, market-size integrity, candidate diversity, independent evaluator, decision engine, and human approval contracts remain authoritative.
- Bridge sessions are in-memory, bounded, TTL-limited, thread-safe, replay-safe, and may be lost on server restart.
- No ChatGPT login automation, cookie extraction, browser-session capture, chatgpt.com scraping, or Plus-to-API credential conversion.
- Existing deterministic CI and real Chromium CI remain GREEN.
